# 今日の3タスクボード（task3board）

1日にやることを「3件だけ」に絞る、超小型のタスクボードです。タスクリストが際限なく長くなるのを防ぐための、あえて小さな道具です。

## 使い方

- **今日のボード**：3つの枠に今日のタスクを書いて「保存する」を押します。空欄の枠は保存されません。
- **完了チェック**：「完了にする」ボタンで完了／未完了を切り替えます。完了したタスクには「完了」と表示されます。
- **履歴**：「過去の日のタスクを見る」から、過去の日のタスクを日付ごとに読み取り専用で見返せます。

日付は日本時間（JST）で判定します。

データは SQLite に保存されます。DB のパスは環境変数 `TASK3BOARD_DB` で変更できます。

## ローカル実行

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

## Render へのデプロイ

`render.yaml` 同梱。無料プラン（free）の Web Service としてデプロイできます（healthCheckPath: `/healthz`）。

## 制限事項（正直なところ）

- タスクは1日3件までです。優先度・期限・繰り返しなどの機能はありません（それがこのツールの狙いです）。
- 過去のタスクは履歴ページで見るだけで、編集や今日への繰り越しはできません。
- ログイン機能はありません。Render 無料プランでは SQLite のデータが再デプロイ等で消える場合があります。
